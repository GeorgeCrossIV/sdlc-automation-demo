# SDLC Automation Demo

IBM Bob demo — full GitHub delivery loop from open issue to green CI pull request.

## Finance App

A React + TypeScript finance analytics dashboard tracking IBM against four competitors across three time ranges (Today, 7 Days, Quarter), plus a user-selected company chart.

## Quick Start

```bash
cd finance-app
npm install
npm run dev          # http://localhost:5173
npm run validate     # lint + test + build
```
